# Security Policy

The following table lists the security support status for versions of this project:

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

Security issues and vulnerabilities should be reported privately to ensure player safety:

1. **Private Disclosure:**
   - Please report vulnerabilities via [GitHub Security Advisories](https://github.com/JoshRob297/halo-ce-server/security/advisories/new) or by reaching out to the maintainer directly.
2. **Details to Provide:**
   - Description of the vulnerability.
   - Exact steps or script to reproduce.
   - Affected platforms (Linux, Windows, Docker).
   - Potential impact on host authority or connected clients.
3. **Response Timeline:**
   - We aim to acknowledge receipt within 48 hours and provide a fix or mitigation timeframe.
